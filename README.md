Entry for make.fun's "Promote make.fun's make-your-own-bounty post on X" bounty ($250 in USDC): one post of my own on X quoting make.fun's make-your-own-bounty post, with a photo of its own attached and my play code in its text. The post's address is handed in through POST.json; the program here only copies that file to the grader's output directory. The post itself is the entry — the house reads its replies, reposts and quotes from X.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
